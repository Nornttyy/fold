# Fold

横屏赛博 4K 音游，三个章节各有四首原创音乐，共 12 首、48 张固定谱面。

## 试玩

[在线试玩](https://nornttyy.github.io/fold/) · D / F / J / K，也支持触屏多指。

本地开发：

```sh
npm start
```

打开 http://127.0.0.1:8812/ 。本地服务只监听本机。源码为原生 HTML / CSS / JS，无第三方运行依赖。

- 全部 12 首曲目、48 张谱面与七步教程均为固定 4K；键位 D / F / J / K，触控可多指操作，无变 K 或暗键。
- 判定线只做平滑的上下颠簸，不倾斜、不旋转、不翻转；音符沿固定横向位置自上而下到达，按键位置始终不动。
- 判定线按每路下一颗音符提前显示收拢光标和充能短线；多押提示为青色，长按时保持引导，不添加文字提示或额外判定对象。
- 全曲使用手工编写的平滑变速段。音符位置按速度积分计算，跨变速点不会跳位、倒退或改变命中时间；EZ 的变速幅度较轻，教程保持恒速。
- 音乐和谱面共用 `src/music-score.js` 的乐器起音数据；音符头及长按尾均定位到 44.1 kHz 的实际起音采样点。难度只筛选音乐事件、编排键位，不在无声空拍补音符；夜航按音乐实际的摇摆镲片节奏编谱。
- 多押跟随爆发段的叠加重音，过渡段减少密度。演示打击音提前 120 ms 排入音频时钟，不再等待画面刷新才播放；暂停会取消待播放打击音，恢复后从当前位置重新调度。
- 仅有 Tap、Hold、Drag，无 Flick。Drag 提前按住对应固定键即可在到达时自动判定，整串不必反复按键；教程包含专门的连锁接住练习。
- note 主体高度为小屏 7 px、大屏 9 px，宽度随轨道适配，桌面上限 154 px。Hold 为亮蓝色，尾带宽度为头部的 38%，带亮色边缘、中轴和稀疏横纹，未按下时也清晰；Drag 为黄色，多押青色描边维持均匀 3 px。教程、引导和命中特效颜色同步。
- 相邻的同轨 Drag 以细黄色光轨连接，按住时点亮；不跨过点击/长按，不连接大空拍，不额外增加判定。
- 舞台高度与背景能量跟随每首实际编排的安静、蓄力和爆发段平滑变化，横向键位不动。
- 点击双层爆点、长按能量环与持续光流、Drag 侧向光轨分别绘制；保留彩色拖尾、辉光、光柱、边缘霓虹和多押冲击环。每路只显示最新一条判定文字。连击每 25 次增加扩散环，50 连击后变为薄荷色。
- 打击粒子在事件发生时生成，最多保留 48 个效果；每路只绘制最强的背景光。系统减少动态效果时关闭粒子、扩散环、光柱和数字缩放，不改变判定。
- 同时按下的音符有发光青色描边；按实际等级区分：1–3 级最多单押、4–13 级最多双押、14–15 级最多三押、16–17 级最多四押。占用中的长按也计入手指上限，避免低级谱面暗藏三押；空心暗色装饰音符不参与判定。
- 同曲四档的音符密度逐级拉开。Drag 集中在每曲两段短连锁，14 级起增加一段，段间至少留八拍间隔；不是把全曲非整拍都设为 Drag。高难段内密集，段外为点击与长按。1–3 级的连锁只用一个键。
- 三章「初醒 / 折光 / 越界」各有四首曲目。初醒：蓝时、夜航、微光、晨频；折光：棱镜、轨迹、电弧、零点；越界：折叠空间、临界、超频、坍缩。每首均有 EZ / HD / IN / AT，等级覆盖 1–17。
- 夜航重编为四路；折叠空间取消变 K 并补回切换段原先空出的节奏。
- 七步入门练习要求实际操作成功才能继续；失败会重试当前练习，不写入歌曲成绩。
- 设置中分别调整音乐、打击音、谱面偏移与下落流速。
- 结算显示点击与长按头的早晚分布和中位偏差。自动接住的 Drag、漏按和演示不纳入偏差统计，不把帧间隔误认为玩家晚按。
- 切到后台或窗口失焦时自动暂停；恢复不跳过歌曲。成绩仅存储在本机浏览器，演示不写成绩。
- 重编后的谱面使用独立的最佳成绩版本键；不删除旧成绩，也不清空音量、偏移及流速设置。
- 主菜单和结算各有独立循环 BGM，与谱面计时时钟分离，进游戏时淡出。浏览器要求第一次真实点击/按键才能解锁音频；首页 ♫ 可开启/关闭界面音乐。
- 按键爆光改用独立透明层的 Web Animations，不在每次命中时读取布局尺寸；下落坐标预计算并缓存，界面使用短过渡。

## 素材与声音

封面及舞台采用本项目的矢量/CSS/Canvas几何设计；没有复用 Phigros 图像、谱面、音乐或打击音。

`src/music-score.js`、`src/expansion-score.js`、`scripts/render-library.mjs` 和 `scripts/render-feedback.mjs` 包含原创音乐及打击音的完整生成来源，`render-audio.mjs` 保留为兼容入口。每首有两个独立爆发段，分别由安静段和渐强铺垫引入；爆发增加失真鼓、Reese 低音、宽声部主音与短促金属音，避免全程堆强度。新曲分别配置旋律、鼓点、低音节奏、包络和段落边界，临界等曲加入低音呼应。48 张谱面按实际起音编排。音乐为 44.1 kHz 双声道 16 位 PCM，不转码以保持起音时间。渲染时输出 `assets/sync-manifest.json`，记录起音、完整乐器数据指纹及 WAV 校验和。只加载当前曲目、两首界面 BGM 和三种打击音；不是微信小游戏发布包。

打击音使用原创架子鼓合成：点击军鼓/边击 85 ms、长按高通鼓 130 ms、接住闭镲 60 ms，无长混响。多押按同时数量衰减增益，并经过压限器；设置中可分别试听三种声音。听感仍需要玩家反馈。

```sh
npm run audio  # 重新离线生成本项目原创 WAV，不联网
npm test       # 谱面、判定、多押、变速、引导、教程、存档、声音及反馈渲染
npm run check
npm run build  # 生成只包含游戏所需文件的 dist/
```

## 当前验证与限制

- 74 项测试通过，全部 48 张谱面均可通过实际引擎输入接口达到 AP；覆盖难度与手指上限、密度分化、Drag 集中段与段间留白、Hold 可见性、早晚统计、音乐起伏和起音对应关系、音频校验和、演示调度、暂停清理及 GitHub 子路径资源。
- 内置浏览器验证章节选曲、横屏菜单与固定按键；截图保存在 `test-results`。
- 未真机测量 iPhone、微信容器、蓝牙耳机延迟或保证所有设备的帧率；已有响应式布局和谱面偏移调节。
- 音乐播放与谱面使用 AudioContext 输出时钟，不以渲染帧数累计时间。
- 所有按键输入只按所属固定键及时间判定，不追踪移动线的触屏坐标。
- 这是 12 首原创试作曲的可玩版本，不是 Phigros 的一比一复制。音乐听感仍需要玩家反馈。

## 发布

独立仓库 `Nornttyy/fold` 使用 GitHub Pages 原生分支发布。`npm run deploy` 先运行语法检查和测试，再构建并推送仅包含游戏文件的 `gh-pages` 分支；GitHub 会自动部署该分支，无须自定义工作流权限。不会在网站公开本地缓存、测试截图或音频制作清单。模块、样式和音频带版本标记，避免更新后混用旧谱面或旧音乐。存档仅在当前浏览器保存，电脑关机不影响在线网站。
